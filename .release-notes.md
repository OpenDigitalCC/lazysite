Release 0.5.41 - Manager security, content tools, and settings clarity

Full suite green (2,295 tests, 152 files); perlcritic clean at severity 3;
compile, tidy, bench, coverage and strict SBOM gates all green.  Channel: edge.

Security
- Bad-URL auto-blocker (SM128, on by default). lazysite now recognises
  vulnerability-scanner probes (/wp-login.php, /.env, /.git/, *.php on a Markdown
  site, ...) and blocks a source IP after it hits too many in a rolling window,
  enforced in the auth wrapper. Configure it on the Plugin Config page; blocked
  IPs and one-click unblock are on the Visitor Statistics page. (Protects
  auth-wrapped sites.)
- Manager accounts can no longer be driven remotely (SM127). An account with
  group-granted manager UI access (the `ui` capability) is refused outright on
  the control-API and MCP transports, a group may not combine `ui` with a remote
  channel (`api`/`mcp`), and the "Connect an AI assistant" panel is shown only for
  genuine agent accounts - closing the path by which a manager account was
  accidentally connected to an agent.

Content tools
- Duplicate a page - a "Duplicate..." action on the Files list copies a file (and
  its brief), the copy owned by whoever made it.
- Migrate a remote page to local (SM096) - a "Migrate to local" action on a .url
  page fetches the remote body through the shared, SSRF-guarded fetch and saves it
  as a local .md you own. The guarded fetch was consolidated into one module
  (Lazysite::Fetch), removing a duplicated SSRF guard.

Appearance
- A previewed or per-page layout with no compatible active theme now falls back to
  the layout's default-theme stylesheet instead of rendering unstyled.

Manager UI
- Site settings reorganised: the manager toggle is now "Enable the manager UI"
  with a note that switching it off runs lazysite as a headless CMS (still fully
  configurable over API/WebDAV/MCP/files); WebDAV moved under a "Services" group;
  the duplicated Appearance entry removed.
- The Audit page shows timestamps in your local timezone (UTC on hover).
- The Stats page gains a proportional audience-split bar for the traffic mix.

Operations
- install.pl --channel edge|stable sets a site's update channel (no install),
  audited as channel-set - pin a deployment to stable for customer rollout, or
  move it back to edge, without hand-editing the conf. Loop it over your docroots
  to set a whole fleet.
- install.pl --force installs an out-of-channel build (e.g. an edge build onto a
  stable-channel site), recorded in the audit log as an operator override.

Also: internal test coverage for several manager read actions (manager-api branch
floor raised to 60), and a batch of recorded feature requests and design
decisions (external auth, feedback cascade, onboarding endpoint, backups
consolidation, A/B testing, backward-compat freeze).
