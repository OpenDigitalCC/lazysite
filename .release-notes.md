Release 0.7.6 - Licensing audit round: third-party notices + self-hosted theme fonts

The input-licence audit (run for the AGPL + commercial-waiver evaluation)
closed clean with two fixes, both in this release event. All gates green;
channel: edge.

- THIRD-PARTY-NOTICES.md ships in the install set: bundled CodeMirror
  5.65.16 is minified with its MIT headers stripped, so the licence and
  copyright are reproduced as MIT requires; debian/copyright gains the
  DEP-5 stanza. Bundling posture stated: everything else is first-party,
  and runtime Perl dependencies are never bundled.
- The theme library (lazysite-layouts, released in step with this cut) no
  longer touches any CDN: all 16 font families are bundled in the release
  packs (SIL OFL 1.1, each family's licence shipped, ~1MB deduplicated
  variable woff2), served first-party via generated fonts.css, with a
  check-no-cdn gate blocking any future external resource load at
  packaging time. STANDING RULE: no CDN anywhere in lazysite or its
  themes - fonts are freely licensed and self-hosted, full stop.

Audit conclusion recorded: no input licence conflicts with an
AGPL-3.0 + commercial-waiver model - one bundled MIT component (now
noticed), dual-licensed Perl dependencies (never redistributed), OFL
fonts (bundled with licences), no GPL-only inputs.
