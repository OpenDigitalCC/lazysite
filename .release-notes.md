Release 0.7.10 - BETA: channel ladder, one-switch history, MCP version tools

The FIRST beta-channel release. Channel: beta - edge sites take it,
stable sites wait for the next certified cut.

Release channel ladder (this release rides its own feature)
- Three deployment speeds: edge (every release, early testing), beta
  (tested, bedding in), stable (certified customer rollout). A site's
  update_channel is the minimum maturity it accepts; one rank map
  drives the installer gate, --channel-check and every CLI validator.
  Cut with release.sh --beta / --final; set per site with
  lazysite/install.pl --channel edge|beta|stable.

Content history: one switch
- Ticking the Content history plugin on Plugin Manager is now ALL it
  takes (the toggle runs the plugin's on_enable hook: initial snapshot
  + recording on). Unticking pauses recording, keeping every version.
  Plugin Config remains the status/recovery surface. Plugins may
  declare on_enable/on_disable lifecycle hooks generally.
- Fixed underneath: removing a site's LAST plugin corrupted
  lazysite.conf by gluing two lines together (latent since the plugins
  page existed); the rebuild is now line-wise, regression-pinned.

AI agents: version history + honest tool docs
- The MCP connector gains list_versions / view_version /
  restore_version (manage_content; restore audited), so agents can
  inspect and undo content changes like the control API always could.
- Discovery fixed everywhere agents learn: capability map + two task
  recipes (restore-from-history; switch-layout - install/activate
  FIRST, delete after), onboarding brief, and ai-connector-tools.md
  brought current (37 tools - six live tools were undocumented,
  including the whole layout-catalogue set: the root cause of the
  audited failed delete-before-switch). The active-layout delete
  refusal now says what to do instead. git-sync remote push/pull is
  documented as operator-only by design.

Also: SM095 sweep polish rides from 0.7.9 for beta/stable-channel sites.

Fleet: edge sites pick this up on the next upgrade run. To put a site
on the new middle rung: sudo -u SITEUSER install.pl --channel beta
--docroot D (or lazysite provision --channel beta for new sites).
