Release 0.7.7 - STABLE: the field-validation round, cured at source

The second stable release. Everything found in live validation of the
0.7.x line is fixed at the root, plus every feature since 0.7.0 reaches
the stable channel: the FastCGI runtime (147x cache hits), the packaged
distribution (four debs, fleet CLI, one-command Hestia onboarding),
sessions, domain aliases, content history + remote sync, self-hosted
theme fonts, first-party analytics maturity, and the licensing notices.

Fleet roll: sudo lazysite upgrade --all
(manual-policy sites skip as configured; run the doctor nowhere - fresh
provisions now come up clean by construction.)

The field-round fixes (all root-caused and regression-tested):
- The audit trail can no longer go silent: umask-proof 0664 creation,
  self-heal, loud warnings naming any lost entry - and a structural
  guarantee suite that fails the build if a future action or CLI verb
  ships unaudited.
- CLI operations now audit: setup-manager, user/group/credential
  operations - one entry per operation from whichever door.
- Split-identity correctness everywhere: secrets mint 0660, the compile
  cache and page cache are written group-writable (umask scope), the
  installer leaves the whole CGI-writable set correct.
- The doctor's chown-handover defect (validated on dito.tech): a
  CGI-owned secret could pass the check via ownership, then lose access
  in the same run's chown. --fix now replicates access across the
  handover and iterates until stable; invariant: a second run reports
  zero failures.
- Actionable permission errors ("run: lazysite check --fix") on
  nav/config saves.
- Unsaved-changes protection on every explicit-save manager page (nav,
  settings, plugin config, appearance, editor), plus an editor fix: the
  collaborative lock is no longer dropped when you CANCEL leaving.
- Logging & forwarding: audit and diagnostics stay separate streams; the
  logging plugin now optionally forwards either to syslog.

Restore rehearsal for this stable cycle: recorded in RELIABILITY.md
(sub-second mechanical restore, full disaster cycle).
