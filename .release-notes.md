Release 0.7.0 - First stable release

The first stable-channel release of lazysite, cut on the passing of the
2026-07-10 eight-dimension review's resolution cycle. All mechanical gates
green at this tag: full suite, bench, coverage at the ratcheted 75%/62%
floors across all eight gated CGIs, strict SBOM, and the new lint gates
(shellcheck, retired-terms, secrets self-tests).

Review resolution (v0.6.10 review -> this release)
- D5 reliability: docs/RELIABILITY.md declares the SLO/RTO/RPO + error
  budget, mapped to the failure-mode evidence; the first timed full-system
  disaster rehearsal is recorded (mechanical restore ~1 s).
- D6 security: STRIDE/ASVS threat model (cleared at review) + the pentest
  declaration with a dated deferral waiver (ADR 0007) + the
  significant-change assessment register. Fixes: auth user-settings readers
  re-paired to :raw (non-ASCII no longer fails auth gates OPEN),
  password-carrying plugin configs chmod 0660 + lazysite-check probes,
  first-party visitor key salted on secret-less sites.
- D7 documentation: the SM138 doc rot swept from every security-tier and
  starter doc; FEATURES.md current; a retired-terms lint makes future
  sweeps unskippable; man pages now ship in the tarball.
- D8 policy: support period declared (five years from this release,
  security fixes on the stable channel); the Declaration of Conformity is
  populated for signature at this cut; the SBOM declares the product
  licence correctly (MIT).
- Coverage: lazysite-oauth.pl 79.0/58.9 -> 99.3/94.6 stmt/branch; mcp +
  oauth join the gate (eight CGIs); floors ratcheted so the Commercial
  regime floor is the enforced floor.

edge sites roll forward as usual.
