Release 0.9.4 - STABLE: security-hardening line, certified

Channel: STABLE. Promotes the 0.9.x security-hardening line to stable. This is a
channel promotion of the bedded-in 0.9.3 beta - the SAME code, validated on edge
(0.9.0/0.9.1) and beta (0.9.2/0.9.3), including a full partner-surface sweep by a
live site agent. No new functional change enters at the stable step. Full gate:
suite + bench + coverage (every production CGI above floors).

The 0.9.x line delivers:
- Cross-plane capability consistency (WebDAV nav/forms -> manage_nav/manage_forms;
  site-backup CSRF; drift guards; in-tool actor backstop).
- Default-off service killswitches (MCP, OAuth, control-API, token exchange) with
  an operator Services panel, read through one shared helper.
- SM042: the Config page saves via config-set (not the retired pseudo-plugin),
  guarded by a key-parity test.
- SM127 token-path fix; domain-check SSRF guard; tenant-token isolation.
- Capability-grid grantability fix (feedback / notifications) + a grid-parity
  guard; form-targets data-loss fix; nav-read path-leak fix.
- WebDAV PUT RFC-4918 409 compliance; expired-token rotation guidance.

BREAKING (unchanged from 0.9.x, operator-recoverable):
- Remote surfaces are OFF by default - enable in Settings -> Services
  (mcp_enabled, oauth_enabled, control_api_enabled, token_exchange_enabled).
- Grant manage_nav / manage_forms to WebDAV nav/form editors (was manage_config).
- Grant `feedback` to agent groups using MCP submit_feedback.
An existing site restores each from the manager UI; nothing is auto-migrated by
design.
