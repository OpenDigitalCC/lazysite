Release 0.6.0 - Stability milestone

A milestone release. No code changes from 0.5.41 - this tag marks a mature,
well-tested feature set and a stability point reached following the eight-dimension
review. It rolls the minor version to reflect that the 0.5.x line has settled: the
capability model (groups-only channel x action), the manager UI, WebDAV / control-API
/ MCP partner surfaces, the security posture (STRIDE threat model, manager/remote
separation, the bad-URL auto-blocker), and the release + install tooling are all in
place and exercised.

All gates green on the same tree as 0.5.41: full suite (154 files, 2335 tests),
perlcritic severity 3, security lint, compile, changed-code tidy, bench (within
tolerance), coverage (floors met), and the strict SBOM / classification packaging.
Channel: edge.

Backward compatibility: unchanged from 0.5.41. This is a marker, not a breaking
release - the backward-compatibility freeze remains a separate, tracked decision.
