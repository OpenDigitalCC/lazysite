Release 0.6.4 - Fix: the SMTP Validate button placement

A one-fix release. All gates green; channel: edge.

Fix
- The SMTP "Validate connection" button (0.6.3) rendered only on the form-smtp
  plugin card, which is hidden whenever the form-handler plugin is enabled - i.e.
  on any site actually using forms - so it was effectively unreachable. It now
  sits in the SMTP connection section of the email handler's wizard / edit form
  on the Plugin Config page, with the staged verdict (host / port / TLS / auth)
  shown inline. It validates the saved settings: save first, then validate.
