Release 0.7.12 - STABLE: manager UX overhaul from live field review

Channel: STABLE - the whole fleet takes this on the next upgrade run.
A large, demo-driven round on the Users, Groups, Sessions and Plugin
surfaces, plus a self-contained 2FA QR and the account editor.

Users & the account editor
- Selecting an account and editing it are two surfaces: the account list
  is a one-line-per-account tree (name, human/AI, sub-user count, and a
  Configure button on the row); editing opens a full-width editor sheet
  the same size at any tree depth, so deep nesting never shrinks it.
- Editor cards: General (Type, Note, Email), Credentials, Groups,
  Capabilities, Account configuration, then a Danger zone. "Move under"
  shows the account hierarchy indented; the open account is carried in
  the URL so a full refresh reopens it.
- Add user is its own card; the group picker and Groups-page members use
  one shared "pick none-or-many" pill control; member changes update in
  place without reloading.

2FA that can't lock you out
- Set up shows a QR to scan (rendered client-side from a newly bundled,
  self-contained QR library - no CDN, no host dependency, in the SBOM),
  the copyable secret, and recovery codes. Enrolment is PENDING until a
  code confirms it, so exploring the control enforces nothing; confirming
  your own account signs you out to sign back in with 2FA.

Sessions & keys
- The page lists active machine keys (AI / API / WebDAV) with revoke,
  alongside browser sessions; usernames link to the account.

Plugin manager
- Rows redesigned (toggle + Configure stacked; info tooltip; core at the
  end). Plugins can hide toggle-driven actions and unlist themselves: the
  payment demo and operator-only logging are off the manager (their
  helpers/config remain). Remote sync's Test connection is gated until a
  remote is set.

Groups
- Restyled to the Users conventions; delete is refused while a group has
  members.

Appearance
- Trying a theme on/off only snapshots when something actually changed.

Also folds in the channel ladder's Site-settings selector, the SM095
permission sweep, and the machine-readable backlog for stable-channel
sites coming from 0.7.11.
