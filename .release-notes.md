Release 0.7.21 - EDGE: domain check distinguishes a certificate coverage gap

Channel: EDGE - a refinement to the SM156 domain check. Stacks on 0.7.20.

Certificate coverage gap vs no HTTPS
- When a domain's TLS check fails, the check now says WHY: a trusted certificate
  that is served but does not cover the host (a SAN/coverage gap - e.g. Hestia
  did not add the new sub-domain to the certificate) is reported as "a
  certificate is served (for X) but does not cover this host - add this host to
  the certificate (e.g. via Hestia SSL)", distinct from "no trusted HTTPS" (an
  expired, self-signed or absent certificate). This points you straight at the
  fix. lazysite still never issues or edits certificates - that stays with
  Hestia / your control panel.
