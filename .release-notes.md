Release 0.7.22 - EDGE: domains panel backlog (public-IP field, cert SANs, switcher)

Channel: EDGE - a batch of domains/check refinements from the backlog. Stacks on
0.7.21.

Set this server's public IP from the panel
- The domain check's proxy/NAT fallback (canonical_ip) is now a field on the
  Domains panel - set the server's public IP(s) without the CLI. Empty =
  auto-detect (from your site address or the server's own address).

Cert-coverage-gap detail names what the certificate covers
- When a served certificate doesn't cover the checked host, the check now lists
  the cert's SANs, so you see exactly which names it covers and that this one is
  missing - "a certificate is served (covers *.example.com) but not this host".

Multi-domain switcher in the file browser
- An editor scoped to several domains (member of several scoped groups) gets a
  "Domain:" switcher in the Files page to pick which content root to browse,
  instead of an empty root the server then denied outside the union. Single-
  domain editors and operators are unchanged.

Also: a regression test locks the create-user group-membership contract (the
2026-07-13 "new-user group dropped on submit" report was already fixed in
v0.7.14; the report predated the fix).
