Release 0.7.28 - BETA: multilingual completion + cache correctness + domains/manager UX

Channel: BETA. Completes the SM179 multilingual feature (engine chrome i18n), makes
language configuration first-class (not conf-only), fixes a class of stale-render
bugs after a conf change, retires the domain "alias" concept in favour of a clone,
and lands a manager UX consistency pass. Stacks on 0.7.27.

Engine-emitted chrome is localised (SM179 P8)
- The bare 404, the no-403.md fallback and the auth reject pages render in the
  host's language via a new i18n layer (built-in English + optional
  lazysite/i18n/<lang>.json overlay, fail-closed to English). The 404 fallback
  also HTML-escapes the request URI. With P1-P8 in, a language set is complete.

Multilingual configuration is first-class
- lang / lang_group are set through domain-set, the CLI, and the Domains Add +
  Configure forms (validated, fail-closed) - previously honoured by the render but
  only hand-editable into the conf. whoami and lang-status detect a set even when
  lang_group is declared only on alias hosts; lang-status is gated on
  manage_content (a translation agent's cap). New docs cover language config and
  the operator + DNS steps to add a language.

Cache correctness under a conf change
- A cached render bakes in the conf (site name, theme, nav, per-host language),
  so a conf-only edit now invalidates the page cache - previously a stale render
  (e.g. Content-Language: en on a host the conf had switched) survived until the
  source changed. mtime-based, correct under CGI and FastCGI alike.

Per-host caches visible in the manager; preview UTF-8 fixed
- Sub-domain renders (lazysite/cache/hosts/<host>/) are now listed on the Cache
  page and clearable per host. The manager preview no longer double-encodes UTF-8.

Domains: the "alias" concept is retired
- A domain alias was only ever a domain created as a copy of another. Add domain
  gains a "Copy settings from" pre-fill; every domain is a flat, independent row.
  The multi-host alias_hosts mechanism is unchanged.

Manager UX + editor
- One group/user picker (token picker), one verb for settings (Edit), one for
  destroy (Delete), Save buttons consistently primary. The editor returns to the
  file's folder on exit and warns clearly on a reserved system file. ADR 0008
  records the stable compatibility-freeze scope.
