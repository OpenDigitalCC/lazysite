Release 0.7.5 - Webserver glue: wire lazysite to anything, test it in one command

The packaged distribution grows from two debs to four, plus the instant
try-it path. All gates green; channel: edge.

Glue packages
- lazysite-apache.deb and lazysite-nginx.deb: complete, commented vhost
  templates for both patterns (plain CGI and the FastCGI pool) plus
  one-command integrators - lazysite-apache-vhost / lazysite-nginx-vhost
  add <domain> --docroot D [--fcgi] - which render the vhost, refuse to
  overwrite, and print (never run) the module/enable/reload/certbot steps.
- nginx engineering notes: try_files replaces FallbackResource; the
  session-cookie carve-out is pure config (cookie-bearing page misses go
  to the CGI auth wrapper, cookie-less to the pool socket); REDIRECT_URL
  is synthesised via a map - a real integration gap nginx exposed.
- docs/reference/webserver-wiring.md (shipped in both debs): the two
  patterns explained once, the six-item front-end contract, and
  copy-paste snippets for Apache, nginx, Caddy, lighttpd, and "any other
  server".

Try it in one command
- `lazysite demo [--port 8080] [--dir PATH]` - scaffolds a scratch starter
  site as the current user and serves it on the built-in dev server,
  printing the URL. dpkg -i to browsable site in one step; re-runs reuse
  the site. (Root refused, as everywhere.)

Also
- build-deb.sh fixed (unbound variable after the dist/ relocation killed
  builds); all four debs now build to the repo dist/ at 0.7.5-1,
  lintian-clean at --fail-on error,warning.
