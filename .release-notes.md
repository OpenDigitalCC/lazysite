Release 0.5.40 - Code-quality gates + documentation debt (review D2/D7)

Full suite green (2,250 tests, 151 files); perlcritic clean at severity 3;
compile sweep, tidy gate, bench, coverage and strict SBOM gates all green.
Channel: edge. No runtime/behaviour change to the request or render path.

Clears the code-quality (D2) and remaining documentation (D7) debt from the
eight-dimension review.

- Perl::Critic gate raised to SEVERITY 3. The move fixed real findings it
  surfaced - unchecked file opens folded into their existence guards, unused
  capture groups made non-capturing - and those policies stay enforced.
  RequireExtendedFormatting is enabled with a 60-character complexity threshold
  (only genuinely complex patterns need /x, keeping short ones clutter-free);
  the access-log parser and a few others now carry a readable /x form. The
  remaining deviations are documented, deliberate house conventions.

- A perltidy formatting profile (.perltidyrc) calibrated to the hand-written
  house style, enforced CHANGED-CODE-ONLY: new and edited lines must be tidy,
  the existing tree keeps its formatting - no whole-tree reformat.

- docs/ACCESSIBILITY.md: an honest WCAG 2.1 AA self-assessment of the manager UI
  and default theme (audited contrast, focus rings, semantic landmarks) with the
  untested areas named.

- Man pages: the CLI tools (lazysite-users, lazysite-check, install) carry POD,
  so `perldoc` works and tools/gen-manpages.pl renders man pages at release.

- Honest coverage-floor accounting: the manager-api branch measurement has
  settled at ~57%, so the earlier run-to-run swing is treated as resolved and
  the override reflects the true figure.
