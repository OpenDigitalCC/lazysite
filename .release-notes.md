Release 0.7.3 - Sessions, domain aliases, and the documentation currency pass

Four work streams in one edge release. All gates green on a quiet tree.

Sessions (SM141 phase 1)
- The Sessions page now lists live sessions (user, signed in, IP, device,
  "this session") with per-session Sign out and per-user Sign out
  everywhere; secret rotation stays the nuclear option. Sessions remain
  signed cookies: a 24h self-pruning login registry provides the listing,
  and a revocation list (sids + per-user not-before) is enforced at cookie
  verification - single -f stat when nothing is revoked. The cookie gains a
  session id; old cookies stay valid until natural expiry and remain
  killable per-user. Corrupt revocation data fails OPEN with a loud warning
  (and a lazysite-check probe) - a broken file must not lock everyone out.

Domain aliases (SM110 phases 1+2)
- alias_hosts: + alias.<host>.<key>: serve the same site under additional
  hosts with their own site_name / theme / layout / nav / search default.
  Override keys are whitelisted - security settings can never vary by Host.
  Alias renders get their own host-keyed cache slots with exhaustive
  invalidation across every edit/clear/theme surface; the primary host's
  caching is untouched.

Alias redirects finished (SM134 follow-ups)
- aliases_temp: front matter for 302 redirects (aliases: stays 301, old
  maps need no migration); the alias map reindexes on move/copy/DAV
  MOVE/COPY/migrate-to-local; a read-only Aliases card on the Files page
  lists the live map with 301/302 badges.

Documentation currency (full feature review)
- Every doc surface reviewed against shipped code: FEATURES.md brought from
  its v0.4.17-era framing to the full 0.7.x story (runtime, packaging,
  sessions, stable channel + five-year support, coverage posture);
  OPERATOR/IMPLEMENTOR/DEVELOPER, starter docs, architecture docs and the
  security significant-change register (SM139/141/142 assessments) all
  current; CHANGELOG omission fixed.
