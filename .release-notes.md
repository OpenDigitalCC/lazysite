Release 0.7.18 - EDGE: group-level domain delegation (SM155) + preview + aliases

Channel: EDGE - refines the SM154 domains admin (0.7.17) from live-testing
feedback. Stacks on 0.7.17.

Group-level domain binding (SM155)
- The delegation binding moves from the per-account setting to the GROUP. A
  group carries dav_scope (content root) + home_domain; adding a member to a
  scoped group both grants editing and confines them to that domain - the
  agency "a team manages a sub-domain" shape, in one step.
- A member of several scoped groups gets the UNION of their content roots
  (consistent with how capabilities union), enforced on every channel: manager
  UI, control API, MCP and WebDAV. Operators (no scoped group) are unconfined.
- The per-account dav_scope/home_domain are dropped (single-source). Set the
  binding on the Groups page > Domain binding, or:
    lazysite group-set clienta-editors dav_scope   content/clienta
    lazysite group-set clienta-editors home_domain clienta.com
    lazysite group-add alice clienta-editors

Domain preview (SM155)
- The Domains panel previews a domain's home page as a public visitor sees it
  under its own Host - rendered server-side, so you can prepare and debug a new
  domain BEFORE DNS/TLS points at it. (With wildcard DNS + wildcard TLS the
  precondition is met for every sub-domain at once.)

First-class aliases (SM155)
- A host can serve the same content as an existing domain (clienta.com +
  www.clienta.com). Add one from the Domains list ("Add alias"), the control
  API (domain-alias-add) or the CLI (lazysite-domains alias --host H --of
  CANONICAL). Aliases are grouped under their canonical with an "alias of X" tag.

Add-form polish
- The add-domain form is grouped (Identity / Presentation) and the theme field
  is a dropdown of installed themes.
