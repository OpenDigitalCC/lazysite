Release 0.9.8 - BETA: caps-within-session fix + submissions viewer v2 + grid polish

Channel: BETA. Fixes and manager-UI improvements on the 0.9.x beta line. No
BREAKING changes, no migration.

Fixes:
- SM186: a granted capability did not show until re-login. Manager pages
  (auth: manager) were not flagged protected, so the server-rendered nav shell was
  cached and served stale (and could leak one user's capability-gated menu to
  another). Any non-public auth level is now uncached, so a grant reflects within
  the session. Adds a "Domains" grant-to-enable nav hint for grant-capable users.
- The Groups capability toggles now line up in an aligned grid.

SM187 - submissions viewer v2:
- The submissions table opens in a scrollable modal (with a form selector when a
  handler holds more than one store).
- A handled row can be deleted (manage_forms, UI only, audited; the store is
  rewritten atomically by a stable per-row id).
- A new least-privilege read_submissions capability + a read_form_submissions MCP
  tool let an agent read submissions over API/MCP without manage_forms;
  form-submissions is gated manage_forms OR read_submissions on both channels.

Full gate before the build: suite + bench + coverage (every production CGI above
floors).
