Release 0.7.14 - EDGE: multi-site (SM151) + field fixes

Channel: EDGE - for field-testing on edge-channel sites (e.g.
edge.explore.lazysite.io). Beta and stable sites do NOT take this build;
update_channel is the minimum maturity a site accepts.

Multi-site under one instance (SM151)
- One lazysite instance serves many domains. Each alias host can be rooted at
  its own content subtree (`alias.<host>.content_root`), so one docroot - one
  auth store, one manager, one AI/MCP endpoint - serves several domains that
  each present to the world as an independent first-class site: its own home,
  navigation, theme, canonical URL, sitemap, feeds, search and static assets.
- The served path is confined under the domain's content root; a bad or
  missing root degrades to the docroot root with a WARN, never a failure, and
  a content root can never reach the lazysite/ management tree. Confinement is
  boundary-safe (an adversarial cross-domain-leakage review hardened every
  realpath check against superstring-sibling escapes).
- A read-only Domains view (manager System nav) lists the configured domains;
  aliases stay operator conf-file territory. Each access-log line now records
  the requesting Host for future per-domain stats.
- Production: the apache/nginx vhost tools gain `rewrites --docroot D`, which
  generates a per-Host rewrite so each alias domain's static files serve
  directly from its content root. (Config-text generated + unit-tested;
  validate against a live web server before relying on it.)

Hestia fleet management
- New `lazysite-hestia-list.sh` lists every lazysite site on a Hestia host
  from Hestia's own registry (web template = lazysite-app), unioned with the
  install markers so lost markers / mismatches are flagged, not skipped.
  `--plain` emits user/domain/docroot for bulk operations. update-all now
  discovers via the lister.

Field fixes
- install.pl channel/policy writes preserve the conf's mode and group across
  the atomic replace - a site-user channel sweep no longer strips group-write
  and leaves the manager unable to save settings.
- The create-user form keeps a group picked but not committed with Enter -
  the account is no longer created groupless.

Verification
- Full suite (193 files, 3535 tests); bench and coverage gates green; tidy
  clean. No restore rehearsal (that is a per-stable-cycle commitment; this is
  edge).
