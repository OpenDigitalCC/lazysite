Release 0.6.6 - Fix: installer ownership repair scoped to root-owned files

A one-fix release for a 0.6.5 upgrade regression. All gates green; channel: edge.

Fix
- The 0.6.5 ownership-alignment pass chowned everything under lazysite/ to the
  docroot's owner AND group. On a site whose docroot group is not www-data this
  stripped the web server's access to the auth store, and the auth wrapper
  500ed on every manager request ("End of script output before headers").
- align_ownership now repairs ONLY root-owned paths (the sudo-install case it
  exists for), never re-owns the CGI's runtime files or operator content, and
  uses the web-server group (www-data when present) - the same default
  lazysite-check uses.
- A site already affected is repaired with:
  sudo perl cgi-bin/tools/lazysite-check.pl --docroot <docroot> --fix
