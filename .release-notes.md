Release 0.7.2 - Packaged distribution: the SM139 arc

lazysite now ships as Debian packages with a fleet CLI - the answer to the
0.6.5 field round's conclusion that per-site sudo tarball installs do not
withstand automation. All gates green; channel: edge.

Packages (built to /srv/projects/packages/)
- lazysite-common.deb: the engine payload at /usr/share/lazysite,
  /usr/bin/lazysite, man pages, the lazysite@ FastCGI pool unit (+
  /etc/lazysite/pools), the site registry /etc/lazysite/sites.d.
- lazysite-hestia.deb: Apache vhost templates for both patterns
  (lazysite-cgi and lazysite-fcgi - visitor traffic to the pool socket,
  session-bearing requests carved out to the CGI auth wrapper) and
  /usr/bin/lazysite-hestia-domain: one-command domain onboarding that does
  a bounded root layout pass then EVERY site-tree write as the site user.

The lazysite CLI
- provision / upgrade / upgrade --all / check / users / dev / sites /
  version. provision and upgrade REFUSE to run as root (the load-bearing
  principle: root never writes into site trees); upgrade --all drops to
  each registered site's owner.
- Fleet policy: update_policy auto|manual per site (install.pl --policy /
  provision --policy); upgrade --all honours channel + policy; --force
  overrides both; --force-security additionally requires the payload's
  release-manifest.json to declare "security_critical": true.

lazysite-check hardening (the field-round lessons, made structural)
- --fix re-runs every check and prints the POST-fix report.
- Effective access evaluated as the CGI identity via ownership+mode
  arithmetic (root-run checks no longer answer for root): conf
  readability, cgi-bin executability, dir traversal, and the new
  manager-layout probe naming the fallback-chrome symptom.
- Queued chmod fixes compose instead of clobbering each other.

Also: the pool launcher honours the SOCKET= pool-conf key (was documented
but ignored); the Hestia INSTALL-RUNBOOK is rewritten around the packages.

Open by design: apt-repo publication (Forgejo) so the dpkg step becomes
apt upgrade.
