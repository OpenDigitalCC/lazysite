Release 0.9.3 - BETA: WebDAV RFC-compliance + token-rotation guidance

Channel: BETA. Continues the 0.9.x beta line, resolving two partner-site-agent
findings ahead of the stable promotion (which is a channel bump of the bedded-in
beta build - no re-cut).

- WebDAV PUT to a missing parent restores the RFC 4918 409 (MKCOL first). 0.9.x's
  SM166 auto-mkcol (201) silently broke the standard and the publishing brief;
  the server now matches the brief. Strict WebDAV clients interoperate and a
  typo'd parent is a 409, not a silent create-in-the-wrong-place.
- Expired-token rotation returns reason=expired + guidance (re-exchange a pairing
  key) instead of a bare "Invalid token". A wrong token stays a generic invalid.

Everything in 0.9.0/0.9.1/0.9.2 is included, including the upgrade checklist:
- Enable the surfaces you use in Site settings -> Services.
- Grant manage_nav / manage_forms to WebDAV nav/form editors (was manage_config).
- Grant `feedback` to agent groups using MCP submit_feedback.
