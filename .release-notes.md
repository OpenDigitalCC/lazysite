Release 0.7.23 - EDGE: Files breadcrumb root icon fix

Channel: EDGE - a one-line UI fix. Stacks on 0.7.22.

The Files breadcrumb root shows its folder icon again
- The site-root breadcrumb was rendering its markup as literal text
  ("<span ...>[folder]</span>") instead of the folder icon. The link callback
  escaped every label - right for path segments (directory names, an XSS guard)
  but wrong for the root item's trusted icon HTML. The root label is now passed
  through un-escaped; segment labels stay escaped. Regression since the 0.7.16
  XSS hardening.
